# 第 3 循环阶段性思想报告

## 1. 本阶段新增的核心问题

第 3 循环在以下抽象问题上取得了实质性推进，而非对第 2 循环的简单重复：

**被重新定义的核心问题：**

1. **“同意”在结构性不公中的可能性条件**——从第 2 循环“保护 vs 自由”的二元争论，下沉为“在什么疲劳水平上、在什么信息条件下、在什么平台行为约束下，骑手的‘同意’从被污染的转变为足够真实的？”这一问题不再是可以被“强制透明”或“知情退出”等技术方案一笔带过的前提，而是必须在制度设计的每一步中被持续追问的元问题。

2. **程序完备性的可完成性边界**——C 在第 2 循环中提出“最低程序门槛”，第 3 循环中 B 和 D 反复挑战其可完成性。核心追问从“程序是否必要”转向“程序门槛清单的制定权属于谁、清单是否可以无限扩展、门槛是否被事实证明可在合理时间内完成”。C 在第 3 轮中接受分层（启动前 vs 启动后），但 B 在第 3 轮中进一步施压：法律初步框架的“正式化”在操作上是模糊的——它可以是两天内的整理成文，也可以是数周的穷尽式分析。C 尚未完全回应这一追问。

3. **退出后责任归属从价值争论转化为经验检验框架**——D 在第 1 轮中做出关键让步：接受试点期间退出不附带任何后果，将“退出是否应附带后果”推迟到数据出具后。A 和 D 的裂痕从“不可化约的价值冲突”转化为“可被试点数据检验的假设”。但 B 和 C 同时指出：A 的“三个条件”框架（证明无策略性诱导、证明信息披露充分、证明保护期规则有效）在操作上可能设定了永远无法满足的举证标准——因为“证明一个否定命题”在逻辑上不可能。A 在第 3 轮中接受 C 的批评，将措辞从“证明无诱导”修正为“在预设操作化指标上未发现统计显著异常”。

4. **“不可预先退出”的原则性基础被精细化为信息质量差异**——D 在第 3 轮中承受了 B 和 C 的对称举证责任追问：如果“证据不足时不施加后果”是一般原则，为什么“不可预先退出”在证据不足时可以坚持？D 的回应是区分错误代价的可逆性（施加后果的错误不可逆，限制选择权的错误可通过数据快速修正）和举证责任的不对称（保护措施适用预防原则，风险分配需要更强证据）。这一区分在第 3 轮中没有被完全消解，但操作化为“试点分两阶段”方案——第一阶段仅当次退出，第二阶段在数据支持时开放预先退出。

5. **“退出零后果”的操作性不稳定**——B 在第 2 轮中揭示：退出后保护期规则造成的收入损失本身就是一种“后果”——不管叫不叫它“后果”。如果保护期规则是强制冷却期 30 分钟，它在功能上就提供了足够的“退出代价”来防止随意化。A 和 D 的“试点期间退出无后果”共识，在操作上依赖于“后果”的狭义定义（仅指事故后的法律责任或保险赔付差异）。D 在第 3 轮中接受 B 的洞察，提出“强制冷却期 15 分钟 + 休息补偿”作为退出后保护期规则——让退出本身有一个非惩罚性的“深思熟虑成本”。

**本阶段仅被重复、未被推进的问题：**
- 保险精算师的持续缺席（自第 1 循环以来未变）；
- 兼职骑手代表的声音缺失（自第 1 循环以来未变）；
- 跨平台休息协同的竞争法限制（律师在第 2 循环已明确，第 3 循环无新进展）；
- 抽象层面的“劳动关系光谱化”、“算法治理规范性基础”、“配送劳动的准公共服务属性”——这些在第 3 循环中未被充分展开。


## 2. 冲突轴与概念地图

### 冲突轴一：自由 / 规训
- **核心张力**：骑手的选择权是自治的内在价值，还是需要在制度引导下才能实现真实性的脆弱条件。
- **支持“自由优先”论证（A）**：
  - 概念：知情同意在信息充分、理解可能、自愿未被强制的条件下是真实自治。制度的目标是净化选择环境，而非替骑手做选择。
  - 隐含前提：骑手在具体情境中有能力基于自身利益做出正确权衡——即使这个权衡与制度设计者的偏好不同。
  - 可被证伪条件：如果试点数据证明在制度赋权全部到位后，退出者事故率仍显著高于未退出者，且退出决策在事后被骑手本人追悔的比例异常高，则“知情自治”的前提被削弱。
- **支持“规训必要”论证（D/B）**：
  - 概念：默认效应和平台操纵在结构性不公中会系统性扭曲骑手选择。高保护作为默认选项、某些条件下限制预先退出——这不是取消自治，而是为自治创造不被操纵的制度条件。
  - 隐含前提：骑手在抽象选择中（预先退出）的决策质量低于情境化选择中（当次退出）的决策质量。行为经济学的默认效应研究可外推至骑手场景。
  - 可被证伪条件：如果试点数据证明在“高保护为默认 + 三层信息结构”下选择降级的骑手比例极低，且独立审计未发现平台诱导降级，则“默认效应会系统性扭曲”的前提被削弱。

### 冲突轴二：照护 / 控制
- **核心张力**：强制安全缓冲是防止骑手在生理上已被疲劳损害时做出危险选择的照护措施，还是以“保护”为名取消骑手对自己生活的决定权。
- **支持“照护”论证（D/职业医学专家）**：
  - 事实：重度疲劳下弹窗效果衰减至与无警告无显著差异（专家结论）。这意味着在某个疲劳水平之后，“知情退出”在生理上已不是真正的知情。
  - 价值：安全是分配正义的底线，不能因自治被交易。当骑手的认知能力已被疲劳实质性损害时，外部权威替代决策是正当的。
- **支持“控制指控”论证（A）**：
  - 概念：保护不能以消灭选择为代价。“知情同意”的生理边界需要个体化验证（专家结论是组间平均值），不能用组间平均值取消个体选择权。
  - 风险：“不可退出”将开创外部权威以保护为名取消选择权的先例，最终伤害灵活就业的合法性。

### 冲突轴三：程序完备性 / 道德紧迫性
- **核心张力**：在科学证据不完全、法律评估未出具的条件下，是应该“先验证后推进”（等待程序基础设施完备），还是“先推进后验证”（以临时基线启动试点，在试点中动态修订）。
- **C 的立场（程序完备性）**：程序不是拖延，而是防止在错误基线上做出不可逆决定的制度免疫系统。最低程序门槛——统一定义、临时基线选定程序、法律初步框架、紧急刹车机制、预注册——是确保试点不制造虚假科学表象的骨架。
- **B/D 的立场（道德紧迫性）**：在程序完善的每一天，骑手仍在无保护的状态下工作。临时阈值的精确数值是“有保护”和“没有保护”之下的次级问题。紧急刹车机制的存在本身就降低了对前置验证的要求。
- **第 3 循环折中**：C 接受“最低门槛分层”（启动前必须完成 vs 启动后第一个月内完成）+“僵局打破机制”。但 C 在第 3 轮中仍坚持法律初步框架必须“正式化”——B 对此追问“正式化”的操作定义。这一张力未完全解决。

### 冲突轴四：自治是否需要代价
- **核心张力（A vs D 的底层分歧）**：选择是否需要附带后果才能确保其“真实性”？
- **D 的立场**：退出若无任何后果，在行为经济学上等同于没有真正的选择——骑手会倾向于随意退出而不深思熟虑。这不是惩罚骑手，而是确保退出是真实决定。D 在第 1 轮中修正：接受试点期间退出无后果，但保留“退出必须附带某种后果”作为核心原则——这意味着 D 认为即使在选择环境被证明显著公正的条件下，退出仍可能需要附带某种后果。
- **A 的立场**：自治不需要代价来确保其真实性。在医疗伦理中，患者拒绝治疗不需要支付“拒绝治疗费”。在劳动保护中，劳动者拒绝安全措施后，法律仍要求雇主维持安全环境。A 在第 3 轮中明确：即使在试点数据证明选择环境公正后，A 仍可能拒绝“退出附带后果”——这是一个哲学分歧，无法被数据完全裁决。
- **可被经验检验的部分**：退出后保护期规则造成的收入损失（强制冷却期）在功能上是否足以让退出成为深思熟虑的决定？B 的洞察——保护期规则本身就是一种“后果”——为这一分歧提供了一个可能被数据检验的操作化路径。

### 冲突轴五：科学权威 / 民主协商
- **核心张力**：疲劳指数阈值的设定应由科学专家决定（疲劳是客观生理现象），还是应由劳资多方协商（“可接受风险水平”是价值选择）？
- **折中框架**：专家提出阈值范围→委员会在范围内选定临时基线→独立审计验证→紧急刹车动态修订。但在“紧急刹车时委员会是否能选择专家建议范围外的数值”这一问题上，科学权威与民主协商的张力仍存。C 在章程草案中要求委员会“不得选择专家建议范围以外的数值”。


## 3. 子讨论组差异

本循环只有一个讨论组（综合视角碰撞组），包含测试角色 A、B、C、D 以及职业医学专家、劳动法律师、真实骑手老张、行业协会秘书处等视角。因此不涉及多个子讨论组的差异化分析。

但需指出：B 和 D 在论证风格和最终关切上的分化在第 3 循环中更加明显。

- **B（教育责任辩护者）**：其功能已从“提出新框架”转化为“守护者和压力测试者”。B 在第 3 轮中集中追问 A 的“三个条件”是否设定了永远无法满足的举证标准，并揭示“退出零后果”在操作上可能被骑手系统性利用而架空安全缓冲。B 的关切从“保护 vs 自由”转向了制度设计在操作上的自洽性。
- **D（弱势经验保护者）**：在第 3 循环中做出了最深的结构性让步——从“退出必须附带后果”到“待检验假设”，从“不可预先退出”到“附带明确可被数据修正的条件”。D 的论证路径从“结构性不公要求外部权威替代决策”转向“结构性不公要求净化选择环境 + 独立监控 + 预设可被证伪的条件”。
- **C（秩序型治理者）**：在第 3 轮中对 D 和 A 同时施加对称举证责任的追问——这是第 3 循环最具方法论深度的一个论证动作。C 接受了分层程序框架，但在“法律初步框架正式化”的操作定义上受到 B 的持续压力。
- **A（自由主义反强制者）**：在第 3 轮中接受 D 的“试点分两阶段”折中方案（附条件），接受 B 对“强制冷却期”作为退出代价的论证，接受 C 对其“证明”措辞的修正。但 A 在“自治是否需要代价”这一哲学分歧上明确不退让——即使试点数据支持选择环境公正，A 仍可能拒绝退出附带后果。

### 4.2 谁提出了最强约束

- **最强事实约束**：职业医学专家——重度疲劳下弹窗效果衰减（组间平均值）；临时阈值建议范围（0.70–0.80/0.85–0.95）；“任务绑定时间”作为核心输入。这些事实不可逆地排除了统一时钟阈值、锁定了疲劳指数模型方向。
- **最强价值约束**：A——自治不需要代价来确保其真实性。这一哲学底线即使面对试点数据也可能不退让，构成了讨论中最深层的不可化约分歧。
- **最强程序约束**：C——试点方案必须预注册；法律初步框架必须在启动前正式化；委员会章程不能空白。C 的追问——对称举证责任、操作化标准的预设——是第 3 循环在方法论上最重要的贡献。


## 5. 第三轮压力测试结果

### 5.1 每个角色承认被击中的地方

- **A 承认**：将“证明无诱导”的措辞修正为“在预设操作化指标上未发现统计显著异常”——承认“证明一个否定命题”在逻辑上不可能。A 接受 D 的“试点分两阶段”折中方案（附条件）——承认“不可预先退出”在第一阶段的合理性需要在试点中验证。A 接受强制冷却期作为退出后保护期规则的主要测试方案——承认退出本身需要一定的“深思熟虑成本”以防止随意化。
- **D 承认**：“退出附带后果”可能被平台武器化来压制退出——承认自己此前未充分考虑的负面效应。接受试点期间退出不附带任何后果——承认“在证据不足时不施加后果”的原则适用于退出后责任归属。接受将“不可预先退出”本身也作为待检验假设——承认举证责任对称性的逻辑力量。接受加强审计机制的具体建议——承认审计能力是解决选择环境公正性问题的关键。
- **C 承认**：最低门槛清单需要分层——承认“程序完备”可能在操作上无法在启动前全部完成。紧急刹车机制降低了对基线精确性的前置要求——承认 B 的逻辑（紧急刹车与前置验证之间存在冗余）部分成立。申诉基线调研可以在启动后第一个月内完成（如果平台 A 拒绝提供数据）——承认数据获取的实践限制。
- **B 承认**：D 的试点分两阶段方案是一个可接受的折中——承认“不可预先退出”与“当次退出”之间的原则区别（信息质量差异）有一定说服力。A 的三层信息结构是可操作的信息披露模板——承认在“充分信息”和“认知负荷”之间需要平衡。

### 5.2 每个角色仍不让步的底线

- **A**：知情退出权不可取消（任何阈值下）；退出后事故后果不可由骑手承担（除非三个条件同时满足）；退出行为不可被标注为偏差；自治不需要代价确保其真实性（哲学底线——即使在试点数据证明选择环境公正后，A 仍可能拒绝退出附带后果）。
- **D**：安全底线不可预先退出（试点第一阶段）；等单期间安全保障不可空白；申诉必须含平台外独立环节，骑手代表不少于三分之一；退出后保护期规则必须足够显著以提供“深思熟虑成本”。
- **C**：试点方案必须在启动前预注册；法律初步框架必须正式化（不可跳过）；委员会章程基本框架不能空白；统一定义不可跳过；紧急刹车机制和僵局打破机制必须内置。
- **B**：强制安全缓冲结构不可被取消（第二级保护的存在不可被投票废除）；申诉终裁不可完全在平台内部；平台 B 的缺席不可阻碍试点；退出后保护期规则不可被弱化为仅有限制高补贴而无强制冷却期。

### 5.3 每个角色提出的未解疑惑和下一轮应追问问题

- **A 追问 D**：在试点数据证明选择环境公正后，D 是否接受“退出可以永久无后果”？还是 D 认为即使在公正环境中，退出仍应附带某种后果？（这是 A 与 D 之间最深的哲学分歧，必须被诚实标注而非假装已解决。）
- **A 追问 C**：最低门槛清单的制定程序是什么？C 是否接受 A 提出的“协会理事会逐条表决 + 三分之二多数 + 异议记录”的程序建议？
- **A 追问劳动法律师**：三层信息结构能否支撑“知情同意”的法律效力？必读层信息是否足够？
- **D 追问 A**：是否承认知情退出权的有效性有一个生理边界？在职业医学专家已证实重度疲劳下弹窗效果衰减的结论面前，A 是否接受在某个疲劳水平之后退出权应转为不可退出？
- **D 追问 C**：在劳动法律师和职业医学专家正式意见可能无法在第 3 循环内全部出具的条件下，是否接受以 compact 中已记录的临时共识作为试点启动的法律和科学基础？
- **B 追问 A**：是否接受“在预设指标上未发现统计显著的异常”作为满足“证明无策略性诱导”的充分基础？如果 A 不接受，A 要求的举证标准是什么？
- **B 追问 C**：法律初步框架的“正式化”是两天内整理成文，还是数周的穷尽式分析？C 要求的是哪个版本？
- **B 追问 D**：是否接受具体的“制度保护被验证有效”的操作化标准（三个具体指标）？如果接受，这些标准是否应写入预注册文件？
- **C 追问 A**：是否接受将“充分且可理解”操作化为具体的、可测量的、预设的阈值（如 70% 即时理解率）？如果 A 不接受，A 是否承认其第二个条件可能永远无法被“证明”满足？
- **C 追问 D**：如果第一阶段数据产生的是模糊结论（部分标准满足、部分不满足），D 是否接受预设的决策规则——由委员会三分之二多数表决，表决理由公开？

## 7. 权限边界

### 7.1 本组织（南澜市即时配送行业协会）可建议/试点的事项

经第 3 循环协商一致，以下事项可在会员协商一致后直接纳入行业自律倡议和试点方案：

1. **双层保护结构**：第一级强制透明（三层信息结构弹窗），第二级默认开启 + 知情当次退出（试点第一阶段不可预先退出，第二阶段在预设标准满足后引入预先退出选项）。含法律防火墙措辞。
2. **疲劳指数模型**：临时基线在专家建议范围（透明 0.70–0.80，安全缓冲 0.85–0.95）内由委员会选定，选定理由公开。
3. **退出后保护期规则**：试点中以 A/B 测试对比“强制冷却期 15–30 分钟 + 休息补偿”和“限制高补贴订单”。
4. **数据信托试点**：委托独立第三方保管数据，退出事件由信托机构独立记录，个人标识数据不得向平台或协会披露，仅提供聚合统计。
5. **多边调解小组**：骑手代表不少于三分之一，公开报告不需平台审阅。
6. **强制休息期间暂停推送热区信息**；休息结束后 15 分钟内骑手有权优先接入待分配订单池。
7. **退出后订单推送序列审计**（多维度指标、反事实分析、实时反馈）。
8. **试点方案预注册**：公开假设、指标、方法、成功标准、制度保护验证标准。
9. **紧急刹车机制**和**僵局打破机制**。
10. **疲劳指数监督委员会**：骑手代表由骑手选举或推荐产生，骑手有权罢免其代表；委员会决议和表决记录公开。

### 7.2 只能继续讨论、不能写成结果的事项

- 退出后事故责任归属（含保险赔付差异）——必须待法律正式意见和试点数据出具后再评估；
- 预先退出权的永久开放——必须在制度保护被验证有效后决定；
- “知情退出权的生理边界”及是否应在极端疲劳水平取消退出权——待职业医学专家正式意见和试点数据；
- 差异化职业伤害保险产品的具体条款——待保险精算师初步评估；
- 跨平台休息协同——当前受竞争法限制，只能讨论，不能试点；
- “退出零后果”是中立基线还是待检验假设——这一方法论分歧未被完全解决，但可在预注册文件中标注。

### 7.3 需要外部主体决定、审批、备案或专业评估的事项

**紧迫（第 4 循环必须推进）：**
1. 劳动法律师正式风险评估意见书——三层信息结构的法律效力、退出后责任分担的可执行性、不作为双重风险的正式法律依据；
2. 职业医学专家正式评估报告——临时阈值建议范围的详细依据、“任务绑定时间”操作定义、弹窗衰减的个体差异、疲劳水平与认知能力的量效关系；
3. 保险精算师初步评估——差异化职业伤害保险产品的保费模型、退出后事故率是否构成独立风险因子。

**中期（试点启动后推进）：**
4. 数据信托方案法律合规审查；
5. 跨平台休息时间协同的竞争法审查（长期议题）；
6. 算法备案与审计立法建议（向政府部门提交）。


## 8. 风险、遗漏与少数声音

### 8.1 假共识风险

- **“双层保护结构”假共识**：各方在概念上趋近，但在“第二级触发阈值的具体数值”、“退出后保护期规则的具体设计”、“预先退出权的开放条件”上仍有深层分歧。第 3 循环已将部分分歧操作化为待 A/B 测试或待预设标准裁决的经验问题，但“测试什么”和“标准由谁设定”本身仍有争议。
- **“试点期间退出无后果”假共识**：A 和 D 在操作上同意试点方案中不包含后果条款，但 A 保留哲学底线（自治不需要代价），D 保留原则底线（退出必须附带某种后果）。这一哲学分歧只是被推迟，不是被解决。
- **“数据信托方案”假共识**：各方接受信托作为概念，但平台 A 的正式合作承诺尚未落地，治理章程的细则仍空白。

### 8.2 权限混淆风险

- 行业协会通过“默认加入—主动退出—公开记录”机制产生实质性约束力，但 A 反复警告其可能演变为“无正当程序的实质惩罚”。公开记录前的平台申诉和纠正程序尚未设计，正当程序防御机制仍空白。
- 疲劳指数监督委员会的“紧急刹车”权限若涉及对平台派单系统的进一步限制，建立在参与平台自愿授予的临时授权上，试点结束后自动终止。但委员会在试点期间的实际权力边界（尤其数据调阅权限）尚未被章程明确界定。

### 8.3 证据不足风险

- 临时阈值建议范围（0.70–0.80/0.85–0.95）基于航空模型外推和初步观察数据，未经专门针对即时配送骑手的验证。试点必须被视为“基于有限证据的审慎估计”。
- 退出后订单推送序列审计的检测能力边界未经验证。平台可能通过审计无法捕获的维度（订单质量标签、长期派单优先级）绕过审计。
- 保险精算师持续缺席——差异化保险产品的任何讨论目前都在真空中运行。

### 8.4 被压低或遗漏的少数声音

1. **兼职骑手**：自第 1 循环以来从未被独立采集。讨论中的“骑手”默认是全职主计型，兼职骑手对强制休息、退出权、收入弹性的偏好可能显著不同。如何防止平台诱导全职骑手“伪装”成兼职以规避保护——这一问题被反复提及但从未推进。
2. **平台 B 骑手**：由于平台 B 拒绝参与，其骑手的声音完全不在讨论中。任何试点结论的推广性因此严重受限。
3. **极端天气/突发事件下的骑手**：讨论默认以常规天气和交通条件为前提。暴雨、高温、疫情封控等极端场景下的保护触发条件是否需要特殊规则——未被充分讨论。
4. **跨平台骑手**：同时在多个平台接单的骑手，其疲劳累积可能来自多平台接单总和，但单平台强制休息无法解决这一问题。律师已明确跨平台协同当前不可行。这一结构性漏洞在讨论中被承认但未被充分回应——任何方案必须接受这一局限并调整对其效果的预期。
5. **消费者行为的真实反应**：透明消费标签实验的前提是消费者愿意为骑手权益支付溢价——这一假设未经验证。消费者行为研究专家持续缺席。


## 9. 下一循环规划建议

### 9.1 应保留的视角

- **A（自由主义反强制者）**：其对知情退出权的坚守、对退出后责任归属的道德论证、对行业协会权力制衡的警惕——是防止保护措施异化为新权力的关键制动器。建议第 4 循环中要求 A 对“知情退出权的生理边界”做出更明确表态。
- **D（弱势经验保护者）**：其在第 3 循环中的修正（退出无后果试点、不可预先退出附带可被证伪条件）是讨论中最深的结构性让步。第 4 循环应要求 D 对“制度保护被验证有效”的操作化标准给出更精确的定义。
- **C（秩序型治理者）**：其对称举证责任的追问、对预注册的坚持、对委员会章程前置完成的要求——是试点方案的程序骨架。第 4 循环应要求 C 对“法律初步框架正式化”的操作定义（两天整理 vs 数周穷尽式分析）做出明确选择。
- **职业医学专家**：须出具正式意见书——这是最低门槛中最紧迫的科学前置事项。
- **劳动法律师**：须出具正式意见书——这是最低门槛中最紧迫的法律前置事项。

### 9.2 应替换或弱化的视角

- **B（教育责任辩护者）**：其核心框架（双层保护结构、疲劳决策陷阱、申诉独立性）已被充分吸收。在第 4 循环中可考虑将其转化为更专业化的认知心理学专家视角——直接测试三层信息结构在模拟疲劳状态下的理解度。这比重复教育责任论证更能推动讨论。

### 9.3 必须新增的视角

1. **保险精算师**（不能再延迟）：差异化职业伤害保险产品的保费模型初步评估。即使只是“给定假设下的范围估计”也比完全空白好。
2. **兼职骑手代表**：对强制休息、退出权、收入弹性的偏好调查；分层保护设计的必要性评估。
3. **认知心理学专家**：三层信息结构在模拟疲劳状态下的理解度和记忆度测试。这直接影响“知情同意”的法律效力评估。
4. **消费者行为研究专家**：透明消费标签的 A/B 测试方案设计；标签对不同收入水平消费者的影响；防止平台在试点期间降低补贴基数以抵消标签效果的监控指标。

### 9.4 第 4 循环必须推进的具体事项（按紧迫性排序）

1. 劳动法律师正式意见书出具（三层信息结构法律效力、不作为双重风险判例基础）；
2. 职业医学专家正式报告出具（阈值依据、疲劳与认知的量效关系、个体差异）；
3. 疲劳指数监督委员会章程基本框架定稿（含骑手代表选举方式、数据访问权限边界）；
4. 试点方案预注册文件草拟（含操作化标准、制度保护验证标准、策略性诱导检测指标的预设）；
5. 数据信托机构选定或推进；
6. 申诉现状基线调研启动（或在平台 A 拒绝配合时正式记录拒绝）；
7. 保险精算师初步联系和评估；
8. 兼职骑手偏好调查方案设计；
9. 试点方案 A/B 测试（强制冷却期 vs 限制高补贴）的实验设计定稿。

### 9.5 第 4 循环必须避免的重复

- 不要重新打开已被科学证伪的统一时钟阈值讨论。
- 不要重新争论已被排除的(c)级法律风险路径（完全不可退出的强制休息）。
- 不要在“是否应该有双层保护结构”、“是否应该有数据信托”、“是否应该有紧急刹车机制”这些已达成临时共识的问题上重复第 2 循环的论证。
- 不要将概念共识（“知情退出权”、“双层保护结构”）等同于方案共识——必须追问操作细节和验证标准。
- 不要在“退出后责任归属”上重开抽象价值争论——应将此问题操作化为待试点数据检验的具体假设，并预设检验标准。
