# 第 2 循环阶段性思想报告

## 1. 本阶段新增的核心问题

第 2 循环在三个相互交织的抽象问题上取得了实质性推进，同时暴露了一个程序性空白和一个认识论困境。

### 1.1 本阶段真正推进的抽象问题

**推进一：照护的合法性边界从抽象哲学命题下沉为可检验的制度命题。**

第 1 循环角色 D 提炼的“照护的悖论”——以公平为名的照护可能利用弱势者的服从性——在本阶段被操作化为具体的检验维度。角色 A 在第 2 轮提出了包含三个分层指标的检验方案（响应率差异、主观体验、非响应者体验），角色 D 在第 2 轮补充了退出率分层分析和响应延迟性分析，角色 B 在第 3 轮接受将“服从性利用成立”作为其 invite-and-respond 模型的否决性指标。这个从先验分析到可检验命题的转化，是本循环最重要的方法论进展。

然而，这个推进同时暴露了自身的边界。角色 D 在第 3 轮指出：“检验方案如果显示‘未发现服从性利用的证据’，这个结果有两种解释：(a) 确实不存在服从性利用；(b) 存在服从性利用但未被测量工具捕获。”这意味着“检验通过”只能作为必要条件而非充分条件——这是一个认识论上的不对称，照护悖论无法通过经验检验被彻底消除。

**推进二：程序正义从抽象原则走向可操作的规程设计。**

角色 C 在第 2 轮给出了数字化退出触发阈值的初步数字建议（焦虑上升 ≥30% 触发红色预警自动暂停、≥20% 触发橙色预警、≥10% 触发黄色预警），并在第 3 轮给出了委员会投票门槛的精细区分（推翻心理中心“终止”意见需三分之二、决定“修改后继续”可简单多数）。角色 D 在第 1 轮交付了匿名群体心理压力监测方案的完整操作框架（指标、频率、预警阈值设定方法、伦理审查流程、触发后响应流程）。这些产出标志着讨论不再停留在“应该有程序”的原则层级，而是进入了“程序如何设计”的操作层级。

**推进三：invite-and-respond 模型经历了从概念框架到操作化草案的压力演进。**

角色 B 在第 1 轮提出了该模型的概念框架，在第 2 轮被角色 C 和角色 D 从执行主体、培训内容、监控机制、效果评估四个维度进行了系统性质询，在第 3 轮被角色 D 以三个压力测试（“告知”是否可能中性、“不跟进”承诺是否可信、模型是否混淆了信息不对称和动机缺失）击中核心前提。角色 B 在第 2 轮修正了执行主体（从辅导员改为同伴学术顾问）、强化了不跟进纪律、接受了服从性利用检验作为否决性指标，并在第 3 轮进一步细化了操作化方案（选拔标准、培训模块、触达方式、监控机制、效果评估）。该模型从第 1 循环的“温和推荐”演进为第 2 循环末的“一次触达、不跟进、告知不推荐”——这是一个在对手批评压力下被大幅修正的版本。

### 1.2 被重新定义的问题

**重新定义一：“强制 vs 自愿”的二元框架被“介入程度光谱”替代。**

第 1 循环的讨论仍以“要不要强制”为默认框架。本循环中，opt-out 模型因心理安全风险在讨论组内被各方拒绝（角色 B 在第 1 循环已撤回，本循环无任何角色持有该立场），讨论光谱从 opt-out / opt-in 的二选一演进为 opt-in / 优化 outreach / invite-and-respond 的三点光谱。角色 A 在第 2 轮提出“分层支持模型”，角色 D 在第 2 轮提出“低风险、高反馈、允许犯错”的自主环境框架，角色 C 在程序层面将措施区分为 A 类（低风险资源型）和 B 类（结构性制度安排）——“强制 vs 自愿”不再是有意义的分析框架，取代它的是“介入程度 + 权力敏感设计 + 退出保障”的多维评估框架。

**重新定义二：“信息收集”从“获得数据”被重新定义为“建立决策的正当性条件”。**

角色 C 在第 2 轮给出了“足够信息”的操作性定义：学业数据（挂科率总体数据 + 至少一个维度的分层）、空间评估（教室可用性清单 + 图书馆数据）、学生意愿调查（抽样完成 + 主要分层可用）。这个定义本身就是一个价值判断——它划定了一条线，线的这一侧是“可以开始做某类决定”，线的那一侧是“必须承认证据不足”。角色 B 在第 3 轮接受这个定义，但附加了两类措施的信息门槛区分（A 类无需等待、B 类必须等待）——这使得“信息收集”从技术性工作被重新定义为讨论组内部的程序性博弈对象。

**重新定义三：“自主权”从绝对基线被重新定义为“需要证明责任分配的争议性基线”。**

角色 B 在第 1 轮挑战“自愿为无需论证的基线”，角色 A 在第 2 轮以“证明责任分配”（克减既有权利比维持既有权利需要更强的正当性证明）回应。在第 3 轮，角色 C 向角色 A 提出更尖锐的追问：角色 A 对“个别化强制安排”的接受，是否意味着“自主权不是绝对的”——如果是，那么“个别化”和“面向全体”之间的区别是原则性的还是程度性的？这个问题迫使自主权从“不可克减的权利”被重新框架为“克减需要满足精准性和必要性条件”——虽然角色 A 尚未在第 3 轮回答（并行发言限制），但这个框架转换已经发生。

### 1.3 本阶段只是重复的问题

以下问题在本阶段被各方重申但未获新推进：

- **学业数据缺位。** 学院管理代表在第 1 循环和第 2 循环完全缺席，未提供任何量化证据。角色 C 的“三维信息需求”清单虽然被各方接受，但截至本循环末无任何新增数据。此问题被重复标识为阻塞因素，但无实质性解决进展。
- **空间改造与制度方案的对比成本分析。** 8 栋宿舍物理改造方案和成本估算未入场。角色 A 和角色 D 反复要求后勤/资产管理方提供信息，但该视角缺席且未提供书面材料。
- **辅导员绩效考核的实际指标。** 此问题被角色 D 反复追问，被角色 C 纳入信息需求清单，但截至本循环末无任何来自学生工作部门或辅导员体系的信息。此问题从第 1 循环的“一般性关注”上升为第 2 循环的“阻塞性信息缺口”，但状态仍是“未获信息”。

### 1.4 本阶段暴露的新问题

**暴露一：invite-and-respond 模型的“告知”是否可能中性——这是一个认识论问题，而非操作问题。**

角色 B 在第 2 轮和第 3 轮将模型精炼为“告知不推荐”，试图通过话术规则区分“信息传递”和“行为建议”。角色 D 在第 3 轮提出了一个根本性的反例：被一个学校认证的学术顾问“告知”资源存在，这个社会事件本身就传递了元信息（“你被认为可能需要这些信息”），改变了被告知者的自我认知情境（“我现在没有了‘不知道’的借口”），并创造了一个隐性的自我解释负担（“为什么我知道了还是不去”）。这个反例揭示的核心问题不是操作层面的（可以通过培训或话术解决），而是认识论层面的：在权力不对等关系中，“告知”作为一个社会事件，是否可能在结构上就不是中性的？这个问题的答案不会因为执行者从辅导员换成学术顾问就改变，因为“被学校认证的角色主动找到你”这个社会事实本身——不管这个角色是否有正式权力——都在一个微小的尺度上复制了“学校主动/学生被动”的关系结构。

这个暴露意味着：即使角色 B 的操作化方案完美执行了“告知不推荐”原则，invite-and-respond 模型仍然可能面临一个无法通过操作优化来消除的结构性伦理问题。这是本循环最深层的未决问题。

**暴露二：invite-and-respond 模型可能成为干预升级的入口——这不是“不跟进”承诺能解决的制度动力学问题。**

角色 D 在第 3 轮构造了一个反例：一旦学校通过 invite-and-respond 模型知道了“哪些学生被告知了但没来”，这个信息本身就构成进一步干预的理由。即使角色 B 承诺“学术顾问不跟进”，学院管理方——在学业预警率的绩效压力下——可能以其他形式跟进（辅导员谈话、学业导师介入）。这个反例揭示的是制度自我保存本能的另一个维度：不仅制度本身会自我维护，制度运行中产生的信息（如“已触达未响应”名单）会自然产生“加强干预”的制度压力。角色 B 可以承诺学术顾问不跟进，但她无法承诺整个学校体系不跟进。这个暴露将讨论从“角色 B 的模型设计”拉到了“该模型在学校制度生态中的实际运作”。

**暴露三：角色 C 和角色 D 在“启动前否决权”上的分歧可能无法通过程序性折中完全闭合。**

角色 D 在第 1 轮主张心理中心在启动前具有否决权（未通过预评估不得启动），角色 C 在第 2 轮提出替代方案（强制预评估 + 有条件放行 + 持续分歧时委员会超级多数裁决）。角色 D 在第 3 轮做出让步但附加了举证责任条件：“在持续分歧的情况下，举证责任在主张启动的一方，而非在心理中心。”这个附加条件触及了一个深层问题：在多角色委员会中，专业判断和民主裁决的关系是什么？如果专业方（心理中心）指出风险但无法“证明”风险的量级（因为心理风险的预测具有固有的不确定性），主张启动的一方是否可以以“风险未能量化”为由要求放行？举证责任的分配实际上决定了在不确定性下谁承担决策失误的主要代价。这个分歧在程序层面可能技术化（投票门槛、举证责任条款），但其底层是专业权威和民主合法性的持续张力——这个张力可能无法在本讨论组内完全解决。

## 2. 冲突轴与概念地图

本循环有六条核心冲突轴。下文每条给出支持论证、反对论证、隐含前提和可被证伪条件。

### 2.1 照护 vs 控制

**核心问题：** 以“为你好”为名的制度介入，其合法性是否必须包含被介入者无条件说“不”的权利？如果“主动告知”本身在权力不对等中就不可能是中性的，那么任何“主动照护”是否在结构上都有控制的一面？

**支持照护（角色 B）：**
- **前提：** 大一新生起点差异巨大，来自教育资源薄弱背景的学生缺乏“主动求助”的行为脚本。形式平等的自由在起点不平等时产生实质不平等的结果。
- **事实：** 图书馆座位缺口 420 个（存在未满足的学习空间需求）；教师一线观察显示学生晚间遇到问题无处问（定性感知）；146 起噪音投诉暗示部分学生宿舍环境不利于学习。
- **价值：** 教育公平要求为起点不利者提供比起点有利者更多的支持——这不能仅通过被动等待求助实现。主动伸手是教育责任的构成部分。
- **修正后方案：** 不是强制，不是默认参与，不是辅导员施压——而是同伴学术顾问的一次性“信息触达 + 社会在场”，严格不跟进，不追求参与率最大化。

**反对照护（角色 D）：**
- **前提：** 任何在权力不对等关系中运作的“主动照护”，如果其有效性机制依赖于弱势方对权威的服从倾向（即使这种服从只是对“学校认证角色”的微妙社会压力），就在结构上构成了服从性利用。
- **事实：** 辅导员存在绩效压力（虽然具体指标未被披露，但角色 D 指出“学业预警率可能影响辅导员考核”是一个合理的制度推断）。学生与任何被学校认证的角色之间都存在权力不对等——即使这个角色没有正式权力。
- **价值：** 照护的合法性取决于被照护者能否说“不”——且这个“不”在制度结构中被真正尊重，而非仅在被话术中被容许。心理安全、自主、尊严优先于通过“温和介入”实现的公平。
- **修正后立场：** 接受自愿模型有遗漏代价，接受照护悖论需要通过检验而不是先验否决。但不能接受任何将“主动触达”建立在“学校认证角色个别化接触学生”基础上的方案——因为这种接触本身就是社会压力的载体。

**隐含前提（角色 B）：**
1. 存在一种“告知”的话语行为，它可以在权力不对等中传递纯粹的信息而不携带社会压力。
2. 同伴学术顾问与大一生之间的年长/经验差距不构成可被感知的隐性权威。
3. 学生能区分“学校认为你应该知道这些信息”和“学校认为你应该去”。

**隐含前提（角色 D）：**
1. 权力不对等关系中，任何由权力方（或学校认证方）主动发起的个别化互动，都携带着不可完全消除的社会压力。
2. 弱势学生的“不求助”不是服从性而是真实的理性选择——即使这种选择在外部观察者看来是“错误”的。
3. 非人格化信息触达（手册、网站、宣讲）的效力虽然较低，但其伦理代价也同样较低——这种不对称使得非人格化触达在道德上优先。

**可被证伪条件：**
- **如果角色 B 的隐含前提 1 为真：** 在小范围受控试点中，被“告知”的学生中，有显著比例回溯性报告“完全不感到任何压力”，且这个比例在不同背景学生中无系统差异。同时，非响应者报告“完全不觉得不响应有任何负面后果”。**检验难度：** 高。因为“感到压力”本身是主观状态，可能不为当事人意识或不愿在问卷中承认（角色 D 第 3 轮已指出这个方法论局限）。
- **如果角色 D 的隐含前提 3 为真：** 纯非人格化信息触达（无任何个别化互动）的资源使用率不显著低于个别化“告知”的资源使用率——即个别化互动不产生额外的行为改变。**检验方法：** 随机对照实验——一组仅接收非人格化信息（手册、邮件、宣讲），另一组接收个别化学术顾问“告知”。如果两组在资源使用率上无显著差异，则个别化“告知”的边际价值不成立。

**后续验证问题：**
1. 角色 B 的“告知不推荐”在受控实验中是否能被学生感知为“纯粹信息”？需要定性访谈补充标准化问卷——特别关注那些“认为自己被叫来所以来”的学生是否能自我报告这一动机。
2. 如果“告知”确实产生了额外的行为改变（相比非人格化信息），这种额外改变的机制是什么？是信息穿透（学生更注意了信息内容），还是社会压力（学生觉得应该响应）？这两种机制在实证上如何区分？

### 2.2 自主权的基线设定——无需论证的默认 vs 需要论证的选项

**核心问题：** 在“自愿参与”和“结构化安排”之间，应该将哪一个设为制度设计的基线（default）？这个基线选择本身是否是一个需要被论证的价值判断，还是一个基于权利的优先预设？

**支持“自愿为基线”（角色 A/D）：**
- **前提：** 成年学生的时间主权是基础性权利。权利的克减需要极强正当性证明——这种正当性证明不仅包括“替代方案可能导致某些代价”，还包括“克减权利是合比例的、必要的、且没有同等有效但侵犯更少的替代方案”。
- **补充论证（角色 A 第 2 轮）：** 克减既有权利比维持既有权利需要更强的正当性证明。这不是认识论的优先性（“自愿在认识上更正确”），而是证明责任分配的优先性（“主张强制者承担举证责任”）。
- **补充论证（角色 D 第 2 轮）：** 主动施加的伤害与被动允许的伤害在道德责任上不对称——前者需要更强的正当性证明。结构化安排是“主动施加”，自愿模型下的遗漏是“被动允许”。

**反对“自愿为基线”（角色 B）：**
- **前提：** 大一学生的时间主权是否等同于“既有权利”是有争议的——因为他们刚从高度管控的高中环境进入大学，尚未在大学环境中实际行使过这个权利。在这个过渡期，将“自愿”设为基线本身就是一个价值选择——它隐含地假设学生已经具备或应该具备自主能力。
- **补充论证（第 1 轮）：** 自愿模型和结构化安排是两个对称的基线选择，各自产生代价。没有哪一个在认识论上具有天然优先地位。基线选择应该是多角色博弈的结果，不应该由一方预设。
- **补充论证（第 1 轮）：** 如果自愿模型系统性遗漏最弱势的学生，它在结果上是不公平的——这种不公平需要被纳入基线选择的考量，而不是被“证明责任分配”的程序规则排除在外。

**程序性立场（角色 C）：**
- 基线选择本身是价值判断，不应由讨论组预设。基线应在信息收集完成后，通过多角色委员会的审议程序产生。这同时拒绝了角色 A/D 的“自愿预设”和角色 B 的“对称性预设”——两者都是未经程序检验的实质立场。

**隐含前提（角色 A/D）：**
1. 时间主权是“既有权利”——即它不需要“能力条件”即可享有。一个尚未发展出时间管理能力的学生，仍然拥有不被安排时间的权利。
2. 证明责任分配本身是一个道德规则，而不是另一个需要被论证的基线选择。

**隐含前提（角色 B）：**
1. 大一新生的过渡期构成一个特殊的制度情境——在这个情境中，“既有权利”的边界是模糊的，不能被简单套用。
2. 将“自愿设为基线”的证明责任分配规则，本身就在价值上偏袒了现状——而现状可能是不公平的。

**可被证伪条件：**
- **如果角色 A/D 的隐含前提 1 为真：** 我们可以观察到，在缺乏外部结构的情况下，不同起点的学生最终（如大二时）在自我管理能力上不存在系统差异——即自由环境本身足以让所有学生（包括起点不利者）发展出自主能力。如果数据显示起点不利者的自我管理能力在大一时显著更低且持续到大二未改善，这削弱了“自由即足以培养自主”的前提。
- **如果角色 B 的隐含前提 1 为真：** 可以观察到，经过大一过渡期的结构化安排（但不是强制管控——而是带有退出机制的温和安排），学生在大二时的自主能力不低于或高于纯自愿模型下的对照群体。如果数据显示结构化安排组的学生在制度撤除后出现更严重的自律崩溃（如角色 A/D 所担忧的），这削弱了“过渡期结构促进自主发育”的前提。

**后续验证问题：**
1. 本校或同类高校是否有纵向数据可以检验大一不同制度环境下学生的自主能力发展轨迹？
2. 如果此类数据不存在（极为可能），讨论组是否应在试点评估中纳入“自主能力发展”作为一个评估维度（例如，通过标准化自我调节学习量表测量基线和大一结束时的变化）？

### 2.3 专业判断 vs 民主认同——治理的合法性来源

**核心问题：** 影响学生时间主权的制度，其合法性主要来自教育者和心理专家的专业判断，还是来自被治理学生的意愿认同？当两者冲突时，如何裁决？

**支持专业判断优先（角色 B/角色 D 部分）：**
- **角色 B（信息不对称论）：** 学生可能因信息不足或短视而反对对自己有益的安排。教师一线观察和心理中心专业评估应具有超越学生主观意愿的权重——不是因为“专家永远对”，而是因为学生在学期初可能尚未充分了解自己的需求和支持资源。
- **角色 D（心理安全不可投票论）：** 心理安全是制度的构成性合法性条件——它不是可以被多数投票权衡的指标。就像建筑必须通过消防审查，方案必须通过心理安全预评估。这不是心理中心有权力，而是方案本身不合法。

**支持民主认同优先（角色 A/C 部分）：**
- **角色 A（自主权论）：** 自主权包含做出“错误”决定并承担后果的权利。制度合法性不仅取决于效果，还取决于程序——被治理者的同意是合法性的构成要素，不是装饰。历史上，专业人士的家长式判断曾导致过教育失误。
- **角色 C（程序合法性论）：** 如果学生意愿调查显示绝大多数学生（包括学业困难者）反对强制，但专业方坚持需要——不推进强制制度。程序正义不仅要求“决策基于信息”，还要求“决策被接受”。在数据和意愿之间存在无法弥合的鸿沟时，正确的回应是诚实记录这个鸿沟，将“证据支持但民主意愿不足”作为不推进的理由。

**冲突裁决框架（角色 C 第 2 轮“分层响应”）：**
- 数据支持强制 + 学生多数反对：不推进强制，但大幅强化自愿型支持 + 更深入的定性研究。
- 数据支持强制 + 学业困难者支持：可能在小群体试点温和结构化安排（仅针对已识别困难且自愿参与的学生）。
- 数据 + 学生双支持：推进试点，但仍需满足全部心理安全/退出触发/监督权硬约束。

**隐含前提（专业判断优先）：**
1. 学生当前的偏好不一定是他们长远利益的可靠指标。信息不对等和延迟满足能力的欠缺，使得未经辅助的学生判断可能系统性低估学术支持的价值。角色 C 在第 2 轮部分支持此前提——他指出“知情选择”前提（提供信息学生就能做出正确选择）在经验上可疑——这同时削弱了纯自愿模型和纯民主模型。
2. 某些价值（如心理安全）的重要性不应受制于多数人是否认识到其重要性。

**隐含前提（民主认同优先）：**
1. 被治理者的内在认同是制度可持续运转的必要条件——一个被多数学生内心反对的制度，即使“专业上正确”，也会在实践中失败（形式出勤、实质无投入）。
2. 不存在一个中立的、不被自身利益和认知偏误影响的“专业判断者”——专家的判断也可能犯错或被制度惯性扭曲。

**可被证伪条件：**
- **如果学生确实短视：** 可以观察到，那些在学期初反对结构化安排的学生，在学期末回溯时改变了看法（尤其在学业困难群体中）。同时，那些支持结构化安排的学生获得了更好的学业结果。这支持“专业判断优先”的一个版本——不是“专家永远对”，而是“学生在有经验后会修正自己的初始偏好”。
- **如果学生不短视：** 可以观察到，学生对结构化安排的初始反对在学期末未改变，且即使在学业困难群体中，反对者也不认为自己的学业困难是由于“没有结构化安排”导致的。这削弱“学生短视”前提。

**后续验证问题：**
1. 学生意愿调查是否可以包含一个回溯性元素——例如在学期末询问“回顾这个学期，你对是否需要晚自习的看法是否改变”——以检验“信息不足导致偏好不真实”的假设？
2. 角色 D 同时持有“心理安全不可投票”和“照护需要被照护者可以说不”——这两者在什么情况下可能发生冲突？例如，如果被照护者多数投票支持一个心理中心认为有风险的结构化安排——角色 D 如何裁决？

### 2.4 短期过渡 vs 长期发展——结构化安排是否促进或延迟自主能力

**核心问题：** 大一第一学期的结构化安排，是帮助学生平稳过渡的临时支架（scaffolding），还是延迟自主能力发展的制度性延迟？

**支持“过渡支架”（角色 B）：**
- 自主能力需要练习，但有效的练习需要支架——明确的目标、可用的工具、逐步减少的支持。从“完全被安排的高中”到“完全自主的大学”之间存在能力断层。在过渡期提供结构，然后逐步放手，不是替代自主，而是提供抵达自主的路径。
- 角色 B 在第 2 轮以学游泳类比：invite-and-respond 是“教练走到犹豫的学生面前说‘我在这里，你可以下来试试，不下也完全没问题’”——这不是替代学生的行走，而是降低面对未知时的焦虑。

**支持“制度延迟”（角色 A/D）：**
- 自我管理能力必须在没有外部结构的真实情境中练习才能获得。学生在外部结构下的“良好表现”不等于建立了可持续的自主能力。更糟的是，结构化安排可能让学生形成对“被安排”的新依赖。
- 角色 D 在第 2 轮以轮椅比喻回应：“如果学生因为长期坐轮椅导致腿部肌肉萎缩，正确的回应是帮他练习走路，而不是给他一个更舒适的轮椅。”角色 B 的回应（“invite-and-respond 是地图而非轮椅”）部分有效，但如果模型在实践中异化为持续引导，它确实会变成轮椅。
- **制度惯性风险（角色 D 第 1 循环）：** “临时”制度极易因沉没成本心理、执行者自我维护、受益者沉默、评估数据的解释弹性而变成永久制度。角色 B 的“一次触达”承诺如果被制度生态中的其他力量突破，就会从“地图”异化为“轮椅”。

**隐含前提（角色 B）：**
1. 大一新生的起点差异非常大，大到“直接放手的自由”在结果上是不公平的。
2. 存在一种“逐步减少支持”的过渡路径——不是在大学四年都提供结构，而是在第一学期提供、第二学期减少、大二完全撤除。这个路径在制度上可以被忠实执行而不被惯性延长。

**隐含前提（角色 A/D）：**
1. 即使过渡期存在能力断层，在自由中犯错并从中学习，比在结构中稳定表现但不发展能力，在长期更有利于学生的自主发展。
2. 制度的“临时性”在组织动力学中很难被保持——因此，与其建立一个“可能变成永久”的制度，不如不建立。

**可被证伪条件：**
- **支持角色 B：** 如果试点数据显示，经历过一学期 structured 非强制晚自习（invite-and-respond 模型配合学术支持）的学生，在大二时的自我调节学习能力不低于纯自愿模型下的对照群体——且弱势背景学生的学业差距在大一末显著缩小。
- **支持角色 A/D：** 如果试点数据显示，invite-and-respond 模型下的大一学生，在制度撤除后的大二上学期出现了显著的自律崩溃或资源使用率大幅下降——即他们从未发展出自主使用资源的能力，只是习惯了“被触达”。

**后续验证问题：**
1. 本讨论组是否有能力进行跨学期的纵向评估？如果没有（因为试点可能只持续一学期），如何在试点评估中纳入“自主能力发展”的短期代理指标？
2. 角色 B 的“逐步撤除”路径是否可以在试点方案中被预设（如第一学期主动触达、第二学期仅维持资源开放不主动触达）——以检验学生在支持减少后的自主行为变化？

### 2.5 代价分配的元规则——如何比较不同性质的代价

**核心问题：** 自愿模型的代价（遗漏沉默弱势者——可能是学业失败甚至退学）与结构化安排的代价（心理压力、自主侵蚀、服从性强化）在什么尺度上可以比较？由谁来比较？如果没有元规则，代价分配框架是否只是一个阻止行动的哲学陷阱？

**支持“可以且必须比较”（角色 B）：**
- 角色 B 在第 1 循环即提出“谁承担代价”的追问，在第 1 轮进一步警告“代价不可比较可能成为维持现状的精致借口”。如果每次我们试图比较代价时，都以“这是价值判断不可消解”为由退回原点，那么代价分配框架就从一个分析工具退化为阻止行动的哲学陷阱。

**支持“某些代价不可被权衡，其他可被分层处理”（角色 C/D）：**
- 角色 D 主张心理安全不是可权衡的指标——它是底线，是不可被“多数受益”正当化去牺牲少数人的维度。在这个底线之上，其他代价（学业、自主、效率）可以在多角色程序中进行比较。
- 角色 C 支持分层处理：区分“构成性条件”（不可权衡——心理安全、退出无审查）、“核心指标”（可权衡但需程序保护——学业、满意度）和“持续条件”（可被管理权衡——资源投入效率）。
- **代价比较的元规则（角色 C 提出，角色 D 部分接受）：** 在特定制度情境下，由多角色委员会在试点前预设各指标的优先序和冲突裁决规则。这不是消除价值分歧，而是将价值分歧在程序中被明确记录和公开辩论。角色 C 承认这个元规则是不完美的——它不能将异质的代价转化为可通约的数字——但它提供了在分歧中做出决策的正当程序。

**隐含前提：**
1. （角色 B）不同类型的代价在严重性上可以被排序——至少在极端情况下（如“退学” vs “轻微焦虑”），这种排序没有争议。可比较性的困难主要存在于中间地带，而非全部。
2. （角色 D）某些代价的性质（如对心理脆弱者的伤害）使得它们不能和另一些代价（如学业成绩的统计改进）放在同一个尺度上——因为前者涉及个体权利的侵害，后者涉及集体福利的增减。功利主义的权衡逻辑在涉及基本权利时不适用。

**未决问题（角色 C 在第 3 轮承认）：**
代价分配元规则的完整建立需要回答“谁有资格比较”的问题——这是政治正当性问题，不是技术问题。本讨论组只能建议元规则的产生程序（多角色委员会、预设优先序、公开辩论），不能越权建立元规则本身——因为讨论组不是民主授权决策机构。

### 2.6 制度的自我约束是否可能——“制度自杀条款”的设计与信任

**核心问题：** 即使我们在制度中预设了退出触发阈值、独立审计、心理安全否决——这些自我约束机制是否能抵御制度自我保存本能的侵蚀？如果执行退出的人恰恰是制度的建立者和受益者，“写进代码”是否真的能对抗组织惯性？

**刚性派（角色 C）：**
- 数字化退出触发——把退出写进代码，不依赖人的意志。触发即暂停，不需要任何人批准。退出阈值由委员会预设，不由行政方单方修改。
- 角色 C 在第 3 轮进一步设计了执行分离：心理中心发出预警信号，本科生院执行暂停，学生组织监督执行。三个角色分离，确保无人能单方阻止暂停。

**怀疑派（角色 D）：**
- 角色 D 在第 1 循环提出“制度自我保存本能”，在第 3 轮进一步追问：(a) 谁来写代码？(b) 谁来监控数据？(c) 如果监控者恰是制度的建立者，他们有什么激励去忠实执行？(d) 数字阈值本身可能被“调整”——如果退出率触发了阈值，行政方是否可以提议“阈值设得太低了，是我们当初考虑不周”然后修改阈值？
- 角色 D 对角色 C“制度的自杀条款”部分接受，但坚持四个条件——特别是自动暂停不可延迟、推翻心理意见需超级多数、心理中心保留公开异议权。这些条件的设计逻辑是：不能仅依赖“预设规则”，还需要权力分置（心理中心触发、委员会裁决、学生组织监督）来对抗制度的自我保存本能。

**未决问题：**
1. 退出触发阈值由谁预设？如果由委员会预设，委员会换届后是否可以修改？如果可以修改，需要什么门槛？
2. 如果制度在触发退出后被委员会复审决定“修改后继续”——这个“修改”本身是否会被执行？“修改”的承诺是否只是让制度在舆论压力下获得延续的修辞？
3. 是否有任何实际的高校制度因预设退出机制而真正被终止的案例？如果有，可以作为“制度自杀是可能的”证据。如果没有（更可能的情况），角色 D 的怀疑有更强的经验基础。

## 3. 子讨论组差异

本轮只有一个综合讨论组（角色 A、B、C、D 四人并行发言 + 交叉质询）。未设置多平行子讨论组。

**本组的讨论目的：** 在四个不同价值视角（自主、公平、程序、心理）之间进行高强度碰撞，压力测试 invite-and-respond 模型的操作化，推进照护悖论的可检验化，构建程序性元协议框架。

**政治/治理观点分布：**
- **角色 A（学生自治代表）：** 自主 > 尊严 > 公平 > 效率。自主权是基线，克减需极强正当性证明。不信任行政单方动机。接受个别化个案强制（三方会商）。反对任何面向全体的默认参与。
- **角色 B（教师/教育责任）：** 公平 > 专业责任 > 心理安全（底线） > 自主。公平需要主动伸手。自主是教育目标而非前提。撤回 opt-out，转向 invite-and-respond。接受心理安全前置和退出自动化。
- **角色 C（管理/程序方）：** 程序合法性 > 可逆性 > 心理安全（底线） > 效率 > 自主。不预设基线。在信息完整前不形成正面制度建议。追求制度自限（退出触发“写进代码”）。
- **角色 D（心理/弱势保护）：** 心理安全（否决性） > 自主 > 尊严 > 公平。照护合法性取决于被照护者能否说“不”。不得利用弱势者的服从性。在程序保护充分的条件下接受强制复审触发权替代否决权。

**最强争点（本组内部）：**
1. 角色 D vs 角色 B：invite-and-respond 模型是赋权还是服从性利用。这是本循环最激烈的交锋轴。
2. 角色 A/D vs 角色 B：自主权是否“无需论证的基线”。
3. 角色 D vs 角色 C：心理安全的制度形式——否决权 vs 强制复审触发权。
4. 角色 A vs 角色 C：委员会中学生代表的席位和投票权重。

**未解决事项：**
1. 角色 B 的 invite-and-respond 模型的核心前提——“告知”在权力不对等中是否可能中性——未被实证检验，也未被角色 B 在认识论层面充分回应。
2. 角色 C 和角色 D 在启动前否决权的举证责任分配上已接近折中，但未完全闭合（角色 D 第 3 轮要求举证责任在主张启动方，角色 C 尚未回应——因并行发言限制）。
3. 角色 A 和角色 B 在“自主权基线”上的分歧在价值层面不可化约——即使转入试点检验，基线选择问题的价值维度仍无法被数据完全解决。

**同质化警告：** 在第 2 循环中，角色 A、C、D 在程序性主张上出现了一定的同质化趋势——三方都支持心理安全前置、退出触发自动化、学生监督权实质化、服从性利用检验。三方的主要分歧在于：(a) 角色 C 的程序框架中，自主权的相对权重低于角色 A/D；(b) 角色 D 主张启动前否决权，角色 C 主张委员会超级多数裁决，角色 A 尚未明确站队。这个同质化是有限度的——在“照护合法性边界”这个核心分歧上，角色 A/D 与角色 B 的张力仍然强烈且未被消解。

## 4. 角色论证路径变化

### 4.1 角色 A（学生自治代表）

**修正：**
1. **不再以先验理由预先否决 invite-and-respond 模型。** 第 2 轮接受该模型在满足五个条件（同伴顾问执行、告知不推荐、不跟进、退出无审查、服从性利用检验作为否决性指标）时可以进入受控试点。这是从“绝对反对任何主动触达”向“有条件接受经验检验”的实质性让步。
2. **接受代价分配框架，公开承认自愿模型有遗漏代价。** 第 1 轮表示愿意接受讨论“可接受的遗漏率”，虽然未给出数字。这是从“自由即为最优”向“自由有代价但代价可被管理”的修正。
3. **强化了“分层支持模型”中个别化强制的接受。** 明确了三方会商的条件和退出条件。这是从“自主权绝对不可克减”向“自主权可被克减但需满足精准性和必要性条件”的微妙但重要的移动——虽然角色 A 尚未承认这个移动等于“自主权不再是绝对原则”。

**坚持：**
1. **面向全体大一学生的默认参与安排（opt-out）在任何条件下不可接受。** 这一点经历两循环压力测试后不被修正。
2. **时间主权是成年学生的基线权利。** 证明责任在主张克减的一方。
3. **制度先例逻辑不可忽视。** 角色 B 和角色 C 尚未充分回应此担忧。

**被挑战最狠的地方：**
- 角色 C 在第 3 轮追问：角色 A 对“个别化强制安排”的接受，是否意味着自主权不是绝对的？如果是，那么“面向全体”和“个别化”之间的区别是原则性的还是程度性的？这个问题击中了角色 A 立场的内核——角色 A 尚未在第 3 轮回应（因并行发言限制）。

**提出的最强约束：**
- **最强事实约束：** 图书馆 420 座位缺口（全体统一的物理不可行）——这是角色 A 反复使用的硬约束，在本循环未被角色 B 挑战。
- **最强价值约束：** “温和的强制比公开的强制更难抵抗”——角色 A 在第 2 轮提出。这个论证直接攻击 invite-and-respond 模型的“温和”外表，指出正因其温和，才更难被学生识别为强制和抵抗。这是对角色 B 模型的独特反击。
- **最强程序约束：** 要求角色 C 明确委员会中学生代表的席位比例（不少于三分之一）和投票权重——将“学生监督权实质化”从原则推向具体数字。

### 4.2 角色 B（教师/教育责任辩护者）

**修正：**
1. **撤回“辅导员作为默认执行者”。** 第 1 轮被角色 D 的权力分析击中后，第 2 轮将执行者改为同伴学术顾问。这是本循环角色 B 最重要的修正。
2. **撤回“话术培训可以解决异化风险”。** 接受角色 D 的论证：在权力不对等中，“关怀”和“施压”的区别不取决于措辞，而取决于接收者的感知。
3. **明确“不跟进”作为模型的构成性规则。** 回应角色 A 的“如果学生不响应，下一步是什么”追问。
4. **明确“参与率最大化不是成功标准”。** 成功标准改为信息触达和障碍降低。这是对角色 C 评估困境和角色 D 服从性利用警告的直接回应。
5. **接受角色 D 的心理安全四级条件、角色 A/D 的服从性利用检验方案作为否决性指标、角色 C 的两类措施信息门槛区分（A 类无需等待三维信息）。**

**坚持：**
1. **不能以“可能异化”为由预先否决 invite-and-respond 模型。** 第 3 轮多次重申。认为角色 D 的论证是先验的，需要经验检验而非预先否决。
2. **不能接受将自愿模型设为无需论证的基线。** 虽然角色 A 以“证明责任分配”回应，角色 B 在第 3 轮未进一步挑战此回应（因并行发言限制），但从其发言脉络看，此底线未被撤回。
3. **不能接受在学术支持资源不到位的情况下推进任何结构性安排。** 这是从第 1 循环就坚持的底线，在本循环被反复确认。

**被挑战最狠的地方：**
- 角色 D 在第 3 轮对“告知是否可能中性”的三个压力测试——被学校认证的人“告知”本身就是社会事件、传递元信息、改变自我认知情境。这是对角色 B 模型核心前提的最强攻击。角色 B 在第 3 轮虽给出了操作化方案（同伴顾问、告知不推荐、不跟进），但未在认识论层面回应“告知作为社会事件是否在结构上就不可能是中性的”。

**提出的最强论证：**
- **“不照护的悖论”：** 第 1 轮提出，第 3 轮重申。这是对角色 D“照护悖论”的对称回应——如果照护有风险，不照护也有风险。要求各方对称地审视两种风险，而非单边聚焦照护的风险。
- **“服从性”对称论证（第 1 轮）：** 弱势学生的“不求助”可能也是服从性（高中训练出来的被动性）。纯自愿模型利用的是“不行动”的服从性。这个论证虽然在第 2 轮被角色 D 以“自我反驳”反击（如果“不求助”是服从性，正确的回应是赋权而非提供新的服从对象），但它在讨论中成功地将“服从性利用”从单向指控变成了双向审视。

**提供的操作化方案（回应 compact 必答题）：**
- 执行主体：同伴学术顾问（大二/大三学生，选拔培训，无正式权力）。
- 培训模块：权力意识教育 + 告知不推荐原则 + 不跟进纪律。
- 触达方式：入学教育期间 5-10 分钟简短会面，一次性的。
- 监控机制：学生组织观察员 + 匿名反馈系统 + 独立审计。
- 效果评估：分层指标（信息触达率、知晓率变化、使用率变化、不使用原因分布）+ 服从性利用检验。成功标准不是参与率，而是信息不对称和障碍的降低。

### 4.3 角色 C（管理/程序方）

**修正：**
1. **接受角色 D 关于“自动暂停不可延迟”的要求。** 给出心理中心触发信号、本科生院执行暂停、学生组织监督执行的三方分离设计。
2. **接受角色 D 关于“超级多数”的要求，并做了精细区分。** 推翻心理中心“终止”意见需三分之二，但委员会决定“修改后继续”可简单多数。
3. **接受角色 D 关于“公开异议权”的要求，附加操作边界。** 隐私保护、程序前置、面向特定对象。
4. **接受角色 D 心理监测方案的核心设计，补充了心理测量学质量验证和解读权透明两个建议。**
5. **给出了“足够信息”的操作性定义和时间节点（8 周）。** 回应角色 B 的“不作为借口”追问。
6. **给出了“数据 vs 学生意愿”张力的分层响应裁决框架。** 回应角色 A 和角色 D 的追问。

**坚持：**
1. **三维信息全部到位前不形成正面制度建议。** 附加时间节点和最低可接受信息集合的操作性定义，但不撤回底线本身。
2. **退出触发阈值不由行政方单方修改。**
3. **学生组织监督权必须实质化。**
4. **对“启动前否决权”持替代方案立场。** 接受启动前强制预评估是合法性构成条件，但在持续分歧时最终裁决在委员会（推翻心理意见需三分之二）。这是与角色 D 四个条件中条件四的持续分歧点。

**被挑战最狠的地方：**
- 角色 D 在第 1 轮提出四个条件，条件四（启动前否决权）是角色 C 和角色 D 之间可能仍有实质分歧的地方。角色 C 的替代方案（强制预评估 + 有条件放行 + 委员会超级多数裁决）试图在专业判断和民主程序之间平衡，但角色 D 在第 3 轮提出举证责任分配条件（主张启动方承担举证责任）——角色 C 尚未回应。

**提出的最强程序约束：**
- **“制度的自杀条款”：** 数字化退出触发——退出率 > X% 或心理指标恶化 > Y% 触发自动暂停。这是对角色 D“制度自我保存本能”警告的最强程序回应。
- **委员会投票门槛的精细区分：** 不是一刀切的超级多数，而是根据决策对心理安全意见的偏离程度设定不同门槛。这是本循环程序设计的最高精度产出。
- **两类措施的信息门槛区分（第 3 轮接受角色 B 的建议的改进版）：** A 类措施（低风险资源型）不需要等待三维信息全部到位；B 类措施（结构性制度安排）必须等待。这解决了角色 B 的“信息不完备不能锁死低风险行动”的核心担忧。

### 4.4 角色 D（心理/公共利益方，弱势保护优先）

**修正：**
1. **接受角色 A 的“照护悖论检验方案”，补充了退出率分层分析和响应延迟性分析。** 这是从先验分析向可检验命题的转化——虽然角色 D 同时警告检验的方法论局限（“检验通过是必要条件而非充分条件”）。
2. **接受角色 C 关于“自动暂停不可延迟”的三方分离设计。**
3. **接受角色 C 关于投票门槛的精细区分。**
4. **在第 3 轮做出重大让步：有条件地接受角色 C 的替代方案作为“启动前否决权”的程序性等价物。** 条件是：“在持续分歧的情况下，举证责任在主张启动的一方，而非在心理中心。”这是本循环角色 D 做出的最实质性让步——从坚持“心理中心单方否决权”退到“启动前强制预评估 + 委员会裁决 + 举证责任倒置”。

**坚持：**
1. **个人退出必须无理由、无审查、无记录。** 两循环未被任何角色实质性挑战。
2. **不得以公平为名利用弱势者的服从性。** 这条底线现在有了可操作的检验维度，但规范性核心不变。
3. **辅导员不能成为“主动触达”执行者，除非其绩效结构被改革。** 角色 B 在第 2 轮已将执行者从辅导员改为学术顾问——角色 D 认可这个修正。但此底线是对未来任何可能重新引入辅导员作为执行者的方案的预警。

**被挑战最狠的地方：**
- 角色 B 在第 1 轮提出“不照护的悖论”和“服从性对称论证”，迫使角色 D 承认自愿模型也有代价并接受代价分配框架。角色 B 在第 1 轮追问“风险 vs 必然”——照护悖论是先验判断还是可检验命题？这迫使角色 D 接受检验方案并做出有条件让步。
- 角色 C 在第 2 轮以治理合法性为由质疑心理中心单方否决权，提出强制复审触发权替代——角色 D 在第 3 轮有条件地接受了替代方案，这是在程序层面的重大退让。

**交付的核心产出：**
- **匿名群体心理压力监测方案操作框架：** 核心指标（焦虑水平、睡眠质量、自主性感知）、辅助指标（求助意愿变化、社会比较压力）、三层预警（黄/橙/红，含具体数字建议但标注为假设性需基线验证）、测量频率（基线/常规/加密）、伦理审查流程、触发后响应流程。这是本循环角色 D 作为专业方的最重要交付。

**提出的最强论证——三个压力测试（第 3 轮）：**
1. **“告知”作为社会事件不可其中性：** 被“告知”本身就是被标记、被传递元信息、改变自我认知情境。这是对角色 B 模型核心前提的认识论攻击。
2. **“不跟进”承诺在制度层面不可信：** 学校体系——而非仅学术顾问——在知道“谁被告知了但没来”后，会产生干预升级的制度压力。
3. **模型可能混淆信息不对称和动机缺失：** 学生不参与可能是因为理性判断（经济压力、认知框架差异），而非信息缺失。对理性判断的不尊重正是照护滑向控制的路径。

## 5. 第三轮压力测试结果

### 5.1 角色 A（学生自治代表）

**承认被击中的地方：**
- 角色 B 的“求助行为差距”论证——承认自愿模型会遗漏沉默弱势者。修正为“分层支持模型”，接受在特定条件下个别化强制（三方会商 + 程序约束）。
- 角色 C 关于“知情选择”前提脆弱性的论证——承认“提供信息 + 尊重选择”可能不足以帮助所有学生。
- “invite-and-respond 模型如果满足严格条件（同伴顾问、不跟进、告知不推荐、服从性利用检验），不反对受控试点”——这是一个实质性让步。

**仍不让步的底线：**
- 面向全体大一学生的默认参与安排不可接受。
- 时间主权是基线权利，证明责任在主张克减方。
- 制度先例逻辑不可忽视。
- 辅导员在绩效结构被改革前不能成为执行者。

**提出的疑惑和下一轮应追问：**
- 向角色 B：invite-and-respond 模型是否可能演变为任何形式的默认安排？防火墙在哪里？
- 向角色 C：委员会中学生代表是否至少占三分之一席位？“搁置学生意愿”是否需要超级多数？——**本循环未获回应。**
- 向角色 D：照护悖论检验方案的独立性如何保障？

### 5.2 角色 B（教师/教育责任辩护者）

**承认被击中的地方：**
- 角色 D 的权力分析——撤回“辅导员作为默认执行者”和“话术培训可解决异化”。
- 角色 D 的“轮椅”比喻——“我承认，如果 invite-and-respond 在实践中异化为持续引导，它确实会变成轮椅。我的‘一次触达、不跟进’设计正是为了防止这种异化。”
- 角色 A 和角色 D 的“服从性利用检验方案”——接受将其纳入评估，且“服从性利用成立”作为否决性指标。这是对角色 D“照护悖论”的最直接回应。
- 角色 C 的“足够信息”定义和时间节点——接受，附条件（两类措施的信息门槛区分）。
- 角色 D 的心理安全四级条件——全部接受。

**仍不让步的底线：**
- 不能以“可能异化”为由预先否决 invite-and-respond 模型。
- 不能接受将自愿模型设为无需论证的基线。
- 不能接受在学术支持资源不到位的情况下推进任何结构性安排。

**提出的疑惑和下一轮应追问：**
- 向角色 D：在同伴顾问执行、告知不推荐、不跟进、独立审计、服从性利用检验作为否决性指标的全部条件下，是否接受 invite-and-respond 进入试点？如果不接受，具体哪个环节还有不可接受的风险？——**这是对角色 D 的最强追问。**
- 向角色 C：是否接受两类措施的信息门槛区分？
- 向角色 A：在同伴顾问不掌握任何评价权力、一次触达不跟进的条件下，是否仍然认为侵犯时间主权？

### 5.3 角色 C（管理/程序方）

**承认被击中的地方：**
- 角色 B 的“不作为借口”追问——接受需要给出“足够信息”的操作性定义和时间节点。
- 角色 D 的“自动暂停不可延迟”要求——接受并给出三方分离设计。
- 角色 D 的“超级多数”要求——接受并做出精细区分。
- 角色 D 的“公开异议权”要求——接受并给出操作边界。
- 角色 D 的心理监测方案——接受核心设计并补充技术建议。
- 角色 B 的“两类措施信息门槛区分”——在第 3 轮接受（A 类不需等待三维信息全部到位，B 类需要）。

**仍不让步的底线：**
- 三维信息全部到位前不形成正面制度建议（现在附加时间节点和最低可接受条件，但底线本身不撤）。
- 退出触发阈值不由行政方单方修改。
- 学生组织监督权必须实质化。
- 对“启动前否决权”持替代方案立场——启动前强制预评估是合法性构成条件，但持续分歧时最终裁决在委员会（超级多数）。这是与角色 D 的持续分歧点。

**提出的疑惑和下一轮应追问：**
- 向角色 D：是否接受“启动前强制预评估 + 有条件放行 + 持续分歧时委员会超级多数裁决 + 举证责任在主张启动方”（回应角色 D 第 3 轮的举证责任条件——**角色 C 在第 3 轮尚未回应，因并行发言限制**）？
- 向角色 A：是否接受“分层响应”框架作为“数据 vs 意愿”张力的裁决原则？
- 向角色 B：请澄清“invite-and-respond 与优化 outreach 之间是否存在原则性区别”。

### 5.4 角色 D（心理/公共利益方，弱势保护优先）

**承认被击中的地方：**
- 角色 B 的“不照护悖论”——承认自愿模型有遗漏代价。修正绝对化立场。
- 角色 B 的“风险 vs 必然”——接受照护悖论需要通过检验而非预先否决。接受将服从性利用检验纳入试点评估。
- 角色 A 的检验方案——接受并补充额外维度。
- 角色 C 关于“自动暂停”和“超级多数”和“公开异议权”的设计——接受。
- **在第 3 轮做出最大让步：** 接受角色 C 的替代方案（启动前强制预评估 + 委员会裁决）替代“启动前否决权”——附加举证责任分配条件。

**仍不让步的底线：**
- 个人退出无理由、无审查、无记录。
- 不得以公平为名利用弱势者的服从性。检验通过是必要条件而非充分条件。
- 辅导员不能成为执行者（除非绩效结构被改革）。
- 心理安全的优先地位必须在程序中被实质性保护——通过自动暂停、超级多数、公开异议权、以及启动前的举证责任倒置。

**提出的疑惑和下一轮应追问：**

- 不得将晚自习出勤与学业成绩简单挂钩（违背教育评价改革方向）。
- 不得设立“公布违纪名单”、“缺勤通报”或类似的公开羞辱实践。
- 任何涉及人脸识别、行为数据分析、位置追踪等技术的部署，必须经过严格的个人信息保护合规评估和伦理审查。

## 8. 风险、遗漏与少数声音

### 8.1 假共识风险

**风险一：各方接受“心理安全前置”但对其制度形式有深层分歧。**

compact 和本阶段报告中将“心理安全必须作为制度设计的前置约束”标记为“临时共识”。这个标记在原则层面是正确的——四方都同意心理安全很重要。但在操作层面，“前置约束”意味着什么？如果意味着启动前否决权（角色 D），角色 C 不接受。如果意味着强制复审触发权（角色 C），角色 D 有条件地接受但附加举证责任条件。如果意味着“写进原则但实际操作中可被委员会投票搁置”，角色 D 不接受。**“心理安全前置”如果不能在操作层面被锁定为具体的、有约束力的程序机制，就有沦为纸面共识的风险。** 讨论组在向上提交建议稿时，必须在“心理安全前置”这一条下明确标注内部的操作性分歧——而不是仅写“四方一致同意心理安全重要”。

**风险二：各方接受“试点”但对“试点失败后是否真能终止”未建立共同信任。**

角色 C 提出“数字化退出触发”作为制度自杀条款，角色 D 有条件接受但持续质疑“写进代码是否真能对抗制度惯性”。角色 B 和角色 A 未对“退出触发是否会被行政方在运行中修改”表达立场。如果讨论组在建议稿中将“退出触发”作为已解决的设计特征写入，却不记录角色 D 对“制度自我保存本能可能侵蚀退出触发”的持续担忧，会产生关于退出机制可靠性的假共识。

### 8.2 权限混淆风险

**风险：建议稿被误写为“本组织已决定”。** 本讨论组是本科生院组织的内部议案讨论会，不是权力决策机构。其产出性质是“建议稿”——建议本科生院可以考虑X、建议本科生院要求Y部门提供Z数据。任何向上提交的文件必须在标题和正文首段明确标注：“本文件是本科生院内部讨论组的建议稿，不构成具有规章效力的决定。所有涉及制度实施的建议需提交校务委员会/教务处等主管机构按规章制定程序审批。”如果这个标注被遗漏，外部阅读者（如学校行政领导）可能将讨论组的“共识”误读为执行决定。这构成权限混淆风险，必须在任何产出文件中被防范。

### 8.3 证据不足风险

**风险一：学业困难的前提持续悬空。** 第 1 循环学院管理代表口头提出“大一课程衔接困难”，但截至第 2 循环末无任何量化证据。角色 B 的“公平起跑线”论证、角色 C 的信息需求清单、角色 D 和角色 A 的检验方案——全部建立在一个未被验证的前提上。如果学业数据最终显示挂科率很低且不集中在弱势群体，整个讨论的紧迫性和必要性基础将被大幅削弱。讨论组在向上提交的任何文件中，必须显式标注：“本讨论组关于‘学业困难’的前提认知目前仅基于间接证据（图书馆座位缺口、噪音投诉的局部性分布、教师一线定性感知）和学院管理方口头陈述（未经数据验证）。在教务处提供脱敏学业数据之前，所有基于‘学业困难’的制度必要论证应在逻辑上被视为‘条件性论证’——如果数据不支持该前提，这些论证的效力自动降级。”

**风险二：辅导员信息缺失阻塞操作化评估。** Invite-and-respond 模型的操作化、角色 D 对执行者激励结构的追问、角色 C 对可行性的评估——全部依赖辅导员实际工作条件的信息。辅导员配比、工作量、绩效考核指标、培训状况、“温和推荐”在实际工作中的实施方式——这些信息完全缺失。在辅导员视角以独立角色入场或相关书面信息被提供之前，任何涉及“主动触达”方案的可行性评估都是悬空的。

### 8.4 被压低的少数声音

**1. 完全沉默的学生（不会参与任何讨论、不会填写问卷的学生）。** 角色 D 在第 1 轮指出：“即使辅导员和高年级学生被引入，我们仍然缺少那些完全沉默、不会参与任何讨论、不会填写任何调查问卷的学生的声音。这些学生可能正是角色 B 的‘公平起跑线’论证所指向的人，也可能是我的‘服从性利用’论证所指向的人。”这个群体在讨论中的代表性问题未被解决——他们不发言、不填问卷、不参与焦点小组。任何基于“学生意愿调查”的决策，都可能系统性地遗漏他们的声音。

**弥补建议（角色 D 第 1 轮提出，本报告支持）：** 学生意愿调查的设计必须包含主动触达沉默者的方法——分层抽样覆盖不同背景、匿名性保证消除填答顾虑、定性访谈补充标准化问卷无法捕获的经验、特别关注那些“从未使用过任何学术支持资源”的学生的理由。但即使采用这些方法，完全沉默者的声音在方法论上仍可能被遗漏。讨论组在建议稿中必须公开承认这个代表性问题，而非把“学生意愿调查结果”当作全体学生声音的无偏差反映。

**2. 兼职/经济压力学生群体。** 此群体在第 1 循环被提及但未以独立视角在讨论中发声。如果晚自习安排在晚间黄金时段，对需要此时段打工维持生计的学生的影响是直接的、物质性的——不是“他们可以选择退出”就能消解的（因为退出可能意味着失去“正常参与”的社会认可）。角色 D 在第 1 轮建议引入此视角作为独立角色或由角色 A 代理——在第 2 循环未实现。

**3. 高年级学生的回溯性经验。** compact 和本阶段报告多次呼吁引入高年级学生代表，但在第 2 循环未实现。大一学生的“自主能力发育轨迹”是一个核心争议——“自由是否能自然培养自主”、“结构化安排是否延迟自主”——而高年级学生是唯一能提供回溯性经验的群体。他们的缺席使得讨论在“短期 vs 长期发展”这一冲突轴上的经验基础薄弱。

### 8.5 方法论遗漏

**遗漏：对角色 D“低风险、高反馈、允许犯错”框架的可行条件缺乏审查。** 角色 D 在第 2 轮提出了这个框架作为替代方案的核心，但角色 C 在第 3 轮指出：这个框架的前提（失败代价低、早期反馈充足、学生有修正机会）在当前学校可能不满足——如果挂科导致退学、如果早期学业预警不覆盖前几周、如果奖学金/保研成绩门槛极高，那么“低风险自主环境”在实践中并不存在。这个追问在第 3 轮才提出，角色 D 尚未回应。如果该框架的前提不被检验，那么以它为理由反对结构化安排的论证建立在可能不成立的条件上。

## 9. 下一循环规划建议

### 9.1 应保留的视角（全部保留）

**角色 A（学生自主）、角色 B（教育公平）、角色 C（程序正义）、角色 D（心理与弱势保护）——四个视角必须全部保留。** 四方之间的张力——自主 vs 公平、照护 vs 控制、专业判断 vs 民主认同——是本讨论组的生产力来源。撤除任何一方都会让讨论失去关键的声音，并可能导致幸存视角在缺乏对立压力的情况下过快形成假共识。

### 9.2 必须引入的视角（下循环开始前必须到位）

**1. 辅导员代表（独立角色——最高优先级）。** 辅导员视角的缺席已被 compact（第 2 循环）和本报告多次标记为阻塞因素。Invite-and-respond 模型的可行性评估、角色 D 对执行者激励结构的追问、角色 C 对“主动触达”操作化的条件——全部依赖辅导员实际工作条件的信息。**如果第 3 循环辅导员视角仍然缺席，讨论组应在该循环结束时正式记录：“因辅导员信息缺失，任何涉及‘主动触达’方案的可行性评估在本讨论组内无法完成。此事项需由本科生院协调学生工作部门提供信息后方可继续。”**——这是程序性的阻塞声明，而非被动的等待。

辅导员应被追问的具体问题：
- 大一新生晚间行为的真实状况是什么？（非学院管理方的笼统判断，而是一线辅导员的实际观察）
- 现有学术支持资源的实际使用率和障碍是什么？
- 在现有工作负荷下，“一对一温和推荐”是否可行？实际工作量是多少？
- 辅导员绩效考核中，哪些指标可能与“学生参与晚自习”产生利益冲突？（学业预警率、挂科率、学生参与活动率等）如果存在，辅导员自身如何感知这种考核压力对“温和推荐”行为的影响？
- 如果 invite-and-respond 模型中的执行者是同伴学术顾问而非辅导员，辅导员认为是否可行？有什么潜在问题？

**2. 高年级学生代表（独立角色——高优先级）。** 大二/大三学生的回溯性经验——“回顾大一，是觉得需要更多自由来学会自我管理，还是后悔当年没人管”——可以为“自主能力发育是否需要外部结构”这一核心争议提供经验质感。本讨论组在 compact 和本报告多次呼吁，但未实现。下一循环必须以独立角色引入。

高年级学生应被追问的具体问题：
- 大一时期，你在多大程度上知道自己需要什么学术支持？你是通过什么渠道知道的？如果你当初不知道，现在回想，什么方式最可能让你当时知道？
- 如果大一时有一个学术顾问（同伴）来告诉你有哪些资源可用，你会觉得这是帮助还是压力？为什么？
- 你现在的时间管理能力，是从大一的自由中自己摸索出来的，还是更希望当初有更多外部结构？

**3. 后勤/资产管理代表（信息提供方，可以是书面信息而非独立讨论角色）。** 提供晚间教室可用性清单、图书馆常态 vs 峰值使用率数据、8 栋宿舍物理改造的初步可行性评估（可改造性、大致周期、成本量级）。不要求参与价值辩论，但要求提供物质可行性信息。

**4. 学院管理代表（必须独立发言或提供书面信息）。** 该视角在第 1 循环和第 2 循环完全缺席，其原始提出的“学业困难”前提在缺乏数据的情况下持续悬空。如果第 3 循环该视角仍不出现，讨论组应正式记录：“学院管理方未提供必要信息（学业数据、制度建议的具体立场），是阻塞本讨论组形成制度建议的原因之一。”

### 9.3 建议新增的对立人格或专家视角

**新增建议一：法务/合规视角（书面咨询而非独立讨论角色）。** 针对本讨论组涉及的多个法律边界问题——大学生时间主权的法理边界、强制安排是否构成变相限制人身自由、个人信息采集（如签到系统）的合规要求——可由本科生院向学校法律事务办公室请求书面咨询意见。这不要求法务人员参与讨论，但要求其提供关于法律红线的专业判断，供讨论组在建议稿中引用。

**新增建议二：校务委员会或教务处代表（作为“外部决策者声音”被引入——听取讨论组的建议并反馈可行性）。** 本讨论组的所有制度建议最终都需要校务委员会/教务处审批。如果在第 3 循环引入一位能“模拟外部决策者反应”的角色（或由本科生院协调实际的教务处人员参与一次），可以帮助讨论组识别哪些建议在实际行政程序中会立即被否决、哪些需要调整形式才能被接受。这可以防止讨论组在内部达成精美折中后，发现外部根本不接受。

### 9.4 下一循环必须避免的重复

**避免一：不要重复“心理安全很重要”的共识声明确认。** 两循环讨论已在该原则上达成一致。下一循环的精力应集中在操作层面——如何将心理安全转化为具体的、有约束力的程序机制（否决权 vs 强制复审触发权、举证责任分配、监测指标的信效度验证）。如果第 3 循环仍停留在“我们都同意心理安全是底线”的宣言层面，讨论将原地踏步。

**避免二：不要重复 opt-out 是否可接受。** 角色 B 已撤回。讨论组内无 opt-out 持有者。第 3 循环不应再将 opt-out 作为讨论对象，而应集中在当前光谱上的三个选项：纯 opt-in + 优化 outreach（角色 A/D）、invite-and-respond（角色 B）、程序优先不预设基线（角色 C）。

**避免三：不要重复“我们需要数据”的宣言。** 信息需求清单已在第 2 循环完成。第 3 循环的任务不是再说“我们需要数据”，而是：(a) 检查数据获取的进展；(b) 如果数据仍未到位，是否触发“证据不足审议程序”——正式记录无法形成制度建议的原因；(c) 如果角色 B 持续主张在数据到位前仍应行动，需要她说明在“最低可接受信息集合”未达到的情况下，主张启动什么措施、以何为证成基础。

**避免四：不要重复角色 B 的“不照护悖论”和角色 D 的“照护悖论”的抽象对撞。** 两方框架已充分展开。下一循环应转入具体问题：(a) 角色 B 的“告知不推荐”在受控条件下是否能被学生感知为纯粹信息（通过定性访谈检验）？(b) 是否存在“告知”的替代方式——同样可以降低信息不对称，但不创造一对一的、由学校认证角色发起的社会互动？(c) 如果非人格化信息触达 + 同伴经验分享会的效果不低于个别化学术顾问告知——角色 B 是否愿意放弃“个别化”这个特征？

### 9.5 下一循环应尝试推动闭合的关键事项

1. **角色 C 回应角色 D 的举证责任分配条件——** 这是“启动前否决权 vs 委员会裁决”分歧能否闭合的最后一步。
2. **角色 A 澄清“自主权的绝对性”：** 个别化强制与“自主权不可克减”的逻辑关系——是原则性的（“自主权不可克减”仍为绝对，个别化只是在同意条件下的支持而非克减），还是程度性的（“自主权可被克减但需满足精确性和必要性条件”）。
3. **角色 B 交付 invite-and-respond 模型的最终操作化方案，并正面回应角色 D 的三个压力测试（特别是“告知是否可能中性”）。**
4. **角色 D 交付“心理监测方案”中关于指标信效度验证的具体方法。**
5. **如果辅导员视角在第 3 循环被引入，基于辅导员实际工作条件信息，重新评估 invite-and-respond 模型的可行性。**
