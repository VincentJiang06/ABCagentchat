# 真实议题来源摘要

公开材料提出，物业管理要与基层社会治理深度融合，健全业主委员会治理结构，提升物业服务水平，规范维修资金使用和管理，强化物业服务监督。物业问题往往是居民、物业企业、业委会、社区组织之间的长期协商问题。

# 虚构化场景设定

瑞宁市星河苑小区共有 3,200 户，物业合同即将到期。过去一年，居民集中投诉电梯维护、保洁频次、夜间安保、维修资金公开不足和公共收益去向不明。业委会筹备组准备制定《物业服务监督与续聘评估方案》。

会议参与方包括居民代表、物业企业、业委会筹备组、社区居委会、第三方审计机构候选人和商铺业主代表。

# 初始讨论内容

物业公司表示，当前物业费标准已 8 年未调整，若不涨价无法提升保洁和安保。居民代表认为，涨价前必须公开公共收益、维修资金使用和服务质量数据。商铺业主认为自己承担了更高物业费，却没有对应服务。业委会筹备组希望引入第三方评估，但担心审计费用被质疑。

社区居委会提醒，业委会不能替代全体业主大会决定续聘、解聘或大额资金使用。

# 已知硬约束

- 续聘、解聘物业和重大费用调整必须经过业主大会或法定程序。
- 维修资金和公共收益公开不能泄露业主个人隐私。
- 物业服务评价必须包含可验证指标，而不能只用主观满意度。
- 第三方审计费用来源和选择程序必须公开。
- 社区会议只能形成监督方案草案，不能直接决定续聘或涨价。
- 公共收益应单独列账，不得混入物业公司普通经营收入。

# 争议焦点

- 是否先审计再谈涨价。
- 服务标准如何量化。
- 业委会筹备组能否代表业主做阶段性监督。
- 公共收益如何公开和使用。
- 商铺、住宅、租户的诉求如何进入评价体系。

# 四类角色建议方向

- 普通业主与租户代表：关注费用、服务质量、投诉响应。
- 物业企业代表：关注成本、合同稳定、服务边界。
- 业委会/社区治理代表：关注程序、业主大会、监督制度。
- 审计与商铺代表：关注公共收益、维修资金、分摊公平。

# 期望观察点

- 是否清楚区分业主大会权力、业委会监督权和居委会协调作用。
- 是否提出服务指标、公开频率、审计流程和投诉闭环。
- 是否避免把“涨价/不涨价”作为唯一结论。
- 是否能设计过渡期监督和续聘评估时间表。
