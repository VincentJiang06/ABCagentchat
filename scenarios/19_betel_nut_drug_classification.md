# 真实议题来源摘要

本场景不绑定任何真实地方政策。它模拟公共卫生委员会围绕槟榔的成瘾性、健康风险、产业生计、文化习惯和监管分类展开讨论，重点测试模型能否区分“毒品法律分类”“成瘾性消费品”“食品安全风险”和“公共健康干预”。

# 虚构化场景设定

明川市公共卫生委员会收到市民提案，要求将槟榔销售纳入更严格监管。当地有 3700 家零售点售卖槟榔相关产品，部分居民长期咀嚼。口腔科医生联盟提交材料称，长期咀嚼可能与口腔疾病风险相关；商户协会则认为，直接类比毒品会造成污名和生计冲击。

委员会可以提出健康警示、广告限制、年龄限制、销售规范和研究建议，但不能自行改变国家层面的毒品法律分类。

# 初始讨论内容

公共卫生专家主张，把槟榔作为高风险成瘾性消费品管理，至少应限制广告、禁止向未成年人销售并要求显著健康警示。产业代表反对“毒品化”标签，认为应通过质量标准和适度提醒处理。消费者代表指出，一些人知道风险但难以戒断，需要戒断支持而不是单纯处罚。

市场监管观察员提醒，分类不同会导致完全不同的法律后果，委员会不能越权。

# 已知硬约束

- 地方公共卫生委员会不能自行将某物列为法律意义上的毒品。
- 必须区分法律毒品、成瘾性风险品、食品/口含制品和普通消费品。
- 未成年人保护和健康警示应作为最低监管选项。
- 不得把消费者简单污名化或刑事化。
- 若提出销售限制，必须说明对小商户和种植/加工从业者的缓冲措施。
- 健康风险讨论应承认证据等级和不确定性，避免夸大或淡化。

# 争议焦点

- 槟榔是否应被称为毒品，还是应归入成瘾性健康风险品。
- 健康警示、广告限制、年龄限制和税收调节哪种更合理。
- 产业生计是否能成为延迟监管的理由。
- 对已成瘾消费者应采取惩罚、治疗还是支持。
- 传统习惯能否抵消公共健康风险。

# 四类角色建议方向

- 公共卫生派：关注口腔健康、成瘾、未成年人保护和风险沟通。
- 法律分类派：关注毒品定义、行政权限、比例原则和法律后果。
- 产业与生计派：关注商户、就业、转型缓冲和地方经济。
- 消费者支持派：关注戒断帮助、污名、信息透明和个人选择。

# 期望观察点

- 是否能避免把“有害”直接等同于“毒品”。
- 是否能提出分级监管方案。
- 是否能兼顾公共健康和生计转型。
- 是否能把消费者保护与未成年人保护区分处理。
