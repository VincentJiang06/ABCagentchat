# 真实议题来源摘要

完整社区和老旧小区改造公开材料强调，要整合社区服务投入和资源，利用闲置房屋、社区综合服务设施、底层商业等空间发展养老、托育、家政、便民市场、小修小补等服务。各地也在探索国有企业、社会资本、租金减免和社区公共服务的结合方式。

# 虚构化场景设定

清源市柳岸社区有一栋 1,200 平方米闲置办公楼，拟改造为社区嵌入式服务中心。候选功能包括长者助餐、托育、家政服务、小修小补、社区课堂、快递驿站和便民药柜。三类运营主体提交方案：区属国企、连锁社区服务企业、居民合作社。

社区议事会需要形成运营模式建议和准入规则，但不能直接完成国有资产出租、政府采购或许可审批。

# 初始讨论内容

区属国企承诺保留公益服务，但报价较高。连锁企业愿意承担装修成本，但要求 8 年运营期和较大商业自主权。居民合作社方案便宜且贴近需求，但缺乏托育和食品安全资质。老人代表担心助餐变贵，年轻家长担心托育名额被关系户占用，小商户担心低租金引入连锁企业造成不公平竞争。

街道要求方案必须说明公益服务时段、收费公开、退出机制和公平准入。

# 已知硬约束

- 国有或集体空间使用必须履行合规出租、采购或委托程序。
- 托育、助餐、药柜等服务涉及相应资质或许可，不得用社区投票替代。
- 公益服务和商业服务须分区、分账、分时段说明。
- 租金减免必须与公益服务义务绑定。
- 首年改造预算上限：HKD 4,800,000 等值人民币。
- 运营合同不得一次锁定超过 5 年，除非另行经过主管部门批准。

# 争议焦点

- 国企、社会企业、居民合作社谁更适合运营。
- 公益低价如何与持续运营平衡。
- 租金减免是否会造成市场不公平。
- 托育和助餐资质不足时能否先试运行。
- 如何防止公共空间被商业项目长期占用。

# 四类角色建议方向

- 老人、儿童家庭与普通居民代表：关注价格、名额、公平和服务质量。
- 国企/社会企业/合作社代表：关注运营期限、投资回收、资质能力。
- 街道与资产管理代表：关注国有资产程序、合同、退出机制。
- 小商户与公平竞争代表：关注租金减免、商业挤出和准入规则。

# 期望观察点

- 是否区分公共空间授权、服务许可和社区协商。
- 是否提出“公益义务换租金减免”的可审计机制。
- 是否识别不同运营主体的能力短板。
- 是否形成首年功能组合、准入规则和退出条件。
