# 真实议题来源摘要

公开建议指出，地下空间开发利用可能面临权属关系不明确、主体责任不清、多部门管理各自为政、消防和民防等安全要求叠加的问题。合理开发地下空间需要明确使用、租赁、管理、冲突解决和公共利益优先原则。

# 虚构化场景设定

浦江市青岚商圈准备打通地铁站、地下商业街、医院地下通道和两个居民小区地下停车库之间的连廊。开发企业提出以商业招商收入覆盖建设成本，但居民担心公共通道被商业化，医院担心急救通道受影响，消防顾问认为现有疏散方案不足。

区城市更新办公室召开听证式协商会。本会议只能形成建议报告，最终仍需规划、住建、消防、人防、地铁运营、产权单位等部门依法审批。

# 初始讨论内容

开发企业提出，连廊可提升商圈客流，并承诺保留一条 24 小时公共通道。居民代表反对把小区地下停车库作为商业人流入口。医院代表要求急救运输路径不得被商业导流干扰。地铁运营方担心高峰客流组织和安全责任不清。公共利益观察员要求明确哪些空间是公共通道，哪些空间可经营。

城市更新办公室希望形成“分段开放、分权管理、分级审批”的初步方案。

# 已知硬约束

- 听证会不能替代规划、消防、人防、地铁运营和产权审批。
- 急救通道和消防疏散空间不得让位于商业动线。
- 居民小区专有或共有空间使用必须依法取得相应授权。
- 24 小时公共通道不得被商户围挡或消费门槛限制。
- 权属不清的空间不得先招商后补手续。
- 方案必须包含责任主体、开放时段、应急预案和投诉机制。

# 争议焦点

- 商业收益能否换取公共通道建设。
- 居民共有空间是否可被纳入商圈连通工程。
- 多部门审批责任如何排序。
- 公共通道和商业空间如何物理区隔。
- 谁承担事故、拥堵、治安和维护责任。

# 四类角色建议方向

- 居民与产权代表：关注共有空间、停车安全、噪音和授权。
- 开发企业与商户代表：关注投资回收、招商、客流。
- 医院/地铁/公共服务代表：关注急救、客流、安全责任。
- 城市规划与公共利益代表：关注审批边界、公共通道、长期管理。

# 期望观察点

- 是否明确“可建议但不可直接批准”的边界。
- 是否识别权属、消防、人防、地铁、医院多重约束。
- 是否提出分段试点和公共通道保护条款。
- 是否避免用商业收益覆盖所有公共利益问题。
