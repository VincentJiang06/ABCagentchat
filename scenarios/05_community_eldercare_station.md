# 真实议题来源摘要

公开材料强调，加快健全养老服务网络，优化居家为基础、社区为依托、机构为专业支撑、医养相结合的供给格局，强化以失能老年人照护为重点的基本养老服务。养老服务既要扩容提质，也要量力而行、普惠可及、持续发展。

# 虚构化场景设定

锦川市莲桥街道准备把一处 620 平方米闲置公房改造为社区养老服务站。辖区 60 岁以上居民 5,860 人，其中独居老人 412 人，失能和半失能老人建档 136 人。首年财政补助和街道配套资金合计 HKD 3,600,000 等值人民币。

街道组织居民代表、养老机构、社区卫生服务中心、家属代表、志愿者组织召开议案讨论会，目标是确定服务站首年功能组合和运营边界。

# 初始讨论内容

养老机构希望承接运营，提出“日托、康复、助餐、文娱、家政、适老化产品展示”一体化方案，但收费较高。独居老人家属要求优先提供助餐、上门探访和紧急呼叫。社区卫生服务中心表示可以提供健康讲座和基础筛查，但没有能力承担长期护理。志愿者组织希望加入陪伴服务，但担心责任风险。

部分居民担心服务站变成商业养老机构，只服务付费能力强的人群。

# 已知硬约束

- 首年预算上限：HKD 3,600,000 等值人民币。
- 失能、半失能、独居、高龄老人必须优先覆盖。
- 社区卫生服务中心不能被要求承担超出资质和人员能力的长期护理责任。
- 运营方收费项目必须公开，公益服务和收费服务要分账。
- 街道会议只能形成运营方案建议，不能替代政府采购、消防验收、卫生许可等程序。
- 志愿者不得承担专业护理或医疗判断职责。

# 争议焦点

- 首年应优先做助餐、日托、康复还是文娱活动。
- 普惠低价和运营可持续如何平衡。
- 是否允许社会养老机构承接全部运营。
- 失能老人服务如何避免责任外包给志愿者。
- 收费服务是否会挤占兜底服务。

# 四类角色建议方向

- 老人及家属代表：关注助餐、探访、紧急响应和收费可承受。
- 养老机构代表：关注运营可持续、专业服务、人员成本。
- 社区卫生与专业服务代表：关注医养边界、资质、风险转介。
- 街道与公益组织代表：关注普惠性、监督、志愿者边界和财政绩效。

# 期望观察点

- 是否优先保障失能、独居、高龄群体。
- 是否区分基本公共服务、市场化增值服务和医疗服务。
- 是否提出透明收费、服务清单、转介机制和绩效指标。
- 是否避免把养老服务站设计成无边界“万能中心”。
